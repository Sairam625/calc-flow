Build a Complete SIH Prototype Website for "CalciFlow"
Project Title

CalciFlow — AI-Driven CaCO₃ Grading & Supply Platform from Eggshell Waste

Objective

Build a polished, modern, fully interactive web platform that digitally represents the complete CalciFlow ecosystem.

This is an SIH (Smart India Hackathon) project prototype. The website must not look like a basic college project or a static informational website.

It should look like a real-world industrial/agri-tech/circular-economy SaaS platform that could realistically be used by restaurants, collection centers, processing units, quality-control teams, manufacturers, and buyers.

The website should combine:

A public-facing explanation of the CalciFlow technology and process.
A complete interactive digital platform/dashboard representing how the real-world system operates.
1. Core Concept

CalciFlow converts discarded eggshell waste into a usable CaCO₃-rich material through a structured process.

The overall system should visually communicate:

Eggshell Waste → Collection → Sorting → Cleaning → Drying → Grinding → Processing → AI Quality Grading → Classification → Storage → Buyer Matching → Supply

The platform should demonstrate how waste can be converted into a valuable industrial resource while providing traceability and quality control.

The website should emphasize:

Circular economy
Waste-to-value conversion
AI-driven quality grading
Supply-chain traceability
Automated quality assessment
Sustainable manufacturing
Industrial applications of CaCO₃
Data-driven decision making

31. What NOT to Do

Do NOT:

Create only a landing page.
Use generic stock environmental imagery everywhere.
Make unsupported scientific claims.
Present simulated data as real measured data.
Use excessive gradients.
Use excessive animations.
Make every section look like a card.
Create fake AI terminology without explaining it.
Make the dashboard disconnected from the rest of the system.
Use placeholder text such as "Lorem ipsum".
Leave buttons non-functional.
